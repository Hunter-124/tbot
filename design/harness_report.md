## Differences from BOM cut lengths
- Longer than BOM: B1IN_P +30, B1IN_N +30 (BOM 46/42 look like routed-only numbers: no +30 applied), SERVO_P/N +17/+19 (module run is 38/43 vs 21/24 modelled), CAP_P +3, JACK_P/N +15 (BOM 35 vs routed 20 + 30).
- Shorter than BOM: lever battery run -18/-13 (routed 99/104 vs 117), SUP_P/N -5/-1, B2IN -16/-13, PI5V -8/-6, CAP_N -1, and all six GPIO wires (IMU -35..-41, ARM/PWM/ARM_GND -12/-10/-11): the router takes shorter diagonal paths than the hand-modelled solid, which wrapped the Pi lobe.
- Treat routed lengths as tool-derived, not hand-verified; physical lay-up decides final cuts.

## Assumptions and honest caveats
1. **Bundle bend radius is overridden.** harness_route sizes any 2+ wire bundle at the NASA-STD-8739.4A estimate (3.5 x bundle OD = 13.3 mm for a 2 x 20 AWG pair, ~16 mm for 4 wires) and demands a 2x-radius straight exit stub; no pair fits this module at that radius. Each segment therefore carries an explicit segment radius override equal to the per-wire radius used to route it (1.5..2.5 mm). Layout.md intends >= 5 mm for pairs and bundles; this is NOT met. Cable datasheet radii are unknown. Review before build.
2. **Per-wire radii** (were 1.5 supplied on all): 2.5 mm for 20 AWG pack/jack leads, PI5V, SERVO, CAP, JACK; 2 mm on SUP, B1IN, B2IN_P, IMU_GND/SDA/SCL; 1.5 mm kept where 2.0 did not route (BATT_*_lever pair, B2IN_N, IMU_VCC, ARM/PWM/ARM_GND).
3. **Pair/bundle envelope.** The router's circular bundle envelope (OD 3.8 for 2 x 20 AWG) cannot pass the narrow passes with 0.3 clearance although a flat pair physically fits. At pinch points I split the bundle with clamp nodes (11 clamp nodes) and set a segment OD override equal to the single-wire OD on those pieces: s22,s26,s30 (B2IN pair, rear lobe pass / bulkhead lower pass), s34,s38 (B1IN pair beside the lever), s43 (servo pair, 1.6), s55,s57 (GPIO exit bundle, 1.1). These sections are only valid if the pair lies flat (stacked) in the opening; not verified physically. Elsewhere bundles use the estimated OD (3.8 / 3.95 / 3.2 / 2.29).
4. Clamp nodes are modelling split points only; no tie points or tie features were added.
5. Wires that share a connector pad (CAP + SERVO on the buck #2 OUT pads) arrive as separate segments; no shared bundle there.
